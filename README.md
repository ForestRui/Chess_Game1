# Chess Game

A browser-based chess game built with vanilla JavaScript, HTML, and CSS.

## Live Demo

Play the game here:

https://forestrui.github.io/Chess_Game1/

## Features

- Legal chess movement validation
- Turn system
- Capturing
- Check, checkmate, and stalemate detection
- Castling
- Pawn promotion
- Computer opponent
- Move highlighting
- Score tracking
- Sound effects
- Responsive design for desktop and mobile

## Technologies

- HTML
- CSS
- JavaScript
- Git / GitHub
- GitHub Pages

## How to Play

Select one of your pieces to see its available moves, then select a destination square.

The game follows standard chess rules.

## Project Purpose

I built this project to practise JavaScript concepts including:

- DOM manipulation
- Event handling
- Arrays and objects
- Game-state management
- Algorithms and move validation
- Responsive web design
